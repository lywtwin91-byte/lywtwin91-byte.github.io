Pixel 베타 펌웨어 · 국가/통신사별 IMS 설정 현황

해석 시 주의 — 펌웨어 안에는 GSMA NSX(Network Settings Exchange)를 직접 가리키는 키·문자열이 없습니다(CarrierSettings·텔레포니 APK dex 전수 검색 결과). 아래 표는 NSX가 배포하는 대상인 통신사별 IMS 설정(VoLTE/VoWiFi/VoNR, SIP·IPsec·ePDG 파라미터, TS.43 Entitlement)이 펌웨어에 실제로 반영된 범위를 보여주는 간접 지표입니다. 어떤 값이 NSX 경유로 들어왔는지는 펌웨어만으로는 구분할 수 없습니다.

국가별 요약

행을 클릭하면 해당 국가의 통신사별 상세가 아래에 표시됩니다. 숫자 = 해당 기능이 활성화된 통신사 프로필 수.

통신사 상세

방법

  • OTA: cubs_beta-ota-cp41.260831.011-f191b637.zip (SHA-256 접두사 f191b637 검증) → payload-dumper-go 로 product, system_ext, modem 추출 → fsck.erofs --extract.
  • Pixel은 CarrierConfig.apk assets XML이 아니라 /product/etc/CarrierSettings/*.pb(통신사별 protobuf 644개 + carrier_list.pb MCC/MNC 매핑 + others.pb 소규모 통신사 680개)를 사용합니다. apns-conf.xml 도 이미지에 없으며 APN 역시 이 .pb 안에 들어 있습니다.
  • 공식 proto 스키마 없이 wire-format 디코더로 직접 파싱(tools/). 값이 통신사 파일에 없으면 default.pb → AOSP 프레임워크 기본값 순으로 적용값을 산출.
  • 국가는 파일명 접미사(ISO-3166), zz = 국제/MVNO/테스트. VoNR = vonr_enabled_bool, NR SA = carrier_nr_availabilities_int_array 에 2 포함, TS.43 = imsserviceentitlement.entitlement_server_url_string 존재, “IMS 상세” = ims./iwlan./imsvoice. 등 IMS 파라미터 오버라이드 5개 이상.
  • 모뎀: MediaTek 모뎀(PIXELMODEM 컨테이너, MCF 파일)으로 Qualcomm MBN 없음. 운영자별 MCF MTK_OPOTA_SBPID_* 406종, MTK_NWOTA_SBPID_* 51종 확인(SBPID→통신사 매핑표는 비공개라 국가 매핑 불가).
  • 원본 데이터: countries.csv · carriers.csv · data.json
